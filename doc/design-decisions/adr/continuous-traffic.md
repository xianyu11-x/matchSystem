# ADR：场景拥有持续流量调度

状态：采纳，2026-09-06。

持续注入需要与手动操作共存，并且不能跨越场景替换。调度器由 Simulator 持有，以当前 runtime 指针标识所属场景，所有注入和匹配仍在 Simulator 锁内执行。成功替换、停止和关闭在同一锁内取消任务，唤醒后的旧调度器必须重新检查归属。

到达与匹配拥有独立 deadline（到期时间）。计时器等待最近到期项，过期工作继续处理并报告延迟，避免固定轮询默默量化间隔或丢弃到达。调度使用实际 Unix 毫秒作为创建与匹配时间；随机种子重放计划间隔和属性序列，不能保证操作系统调度重放。

匹配复用 beginRound/produceAll，不构造虚假 Match。属性复用 GenerateBatch，每条生成使用独立派生种子，支持生成器扩展，代价是逐条生成的编译和分配成本。此实现不承诺高负载吞吐 SLA；长期运行的池和事件内存仍需用户控制。

任务为易失运行状态，不存入场景文件，也不在服务重启后自动开始。详细操作以[持续流量](../../simulator/continuous-traffic.md)为准。
