# 属性生成采用精确序号抽样

状态：接受（2026-09-06）。

大整数集合不能经 JavaScript Number 或全量展开。新增独立的属性生成契约，以十进制文本传输端点，后端合并区间并用 big.Int 容量和序号定位。旧配置保持兼容，避免改变现有随机序列。

采用均匀、取小、取大、平均四种无浮点参数分布；不放回时在剩余有序候选上应用分布。抽取数量限制 4096 以约束每 Ticket 输出，集合容量不受该限制。字符串按首次出现顺序，整数按升序。具体语义以[使用说明](../../simulator/attribute-generation.md)为准。

派生值采用显式 `source` 与 `ref`，共享单位为一条 Ticket 内的完整同类型值，不隐式跨类型转换。依赖图在生成前验证，以排序深度优先遍历确定顺序；来源只求值一次，消费者复制值而不重新抽样。这样可保持种子可重放和关联一致，避免“相同分布”被误认为“同一个值”。
