# 界面操作与配置

从运行总览按“配置规则 → 注入对象 → 分析结果”完成一次模拟。侧栏和窄窗口顶部均有
四个页面的导航；键盘用户可通过“跳到主要内容”和可见焦点定位操作。

## 匹配对象

对象列表支持 25/100/250 条分页和首页/前后页导航。搜索、状态或页大小改变时返回首页；
实时队列变化可能移动偏移分页边界，列表不承诺跨页快照一致性。表单标签和控件字号统一
提高到 13/14 px，并补充清晰键盘焦点，网格内字段保持顶部对齐。


“新建 / 批量生成”内选择目标规则与节点，再选择单条输入或批量与持续流量。折叠面板
不会丢失当前输入，切换规则会按新字段声明重新初始化属性与事实；离开页面后草稿不保留。

- 单条输入的属性和 Object Facts 来自当前 Contract。空白字段省略，字符串/uint64
  列表支持英文逗号、中文逗号或换行。非法整数、溢出值会显示字段名和范围，不再静默过滤。
  手动数字输入受 JavaScript 安全整数限制，完整 int64/uint64 边界可使用批量生成器的
  十进制文本参数。更多选项可指定创建时间（Unix 毫秒）和路由亲和键。
- 批量生成先设置数量、随机种子和起始 ID，再启用所需属性。分布、集合和共享值详见
  [属性生成配置](attribute-generation.md)。提交前检查区间范围、重叠集合基数、不重复
  抽样数量、缺失/循环共享引用和末尾 ID，服务端仍执行权威校验。
- “共同对象事实”给每条生成对象附加相同 Object Facts，也用于持续流量；不是 Provider
  声明或 Match Facts 配置。字段仍来自当前规则的 object scope。
- 更多选项可设置批量创建时间、每条时间步长、亲和键/请求标识前缀和失败时整批撤回。
  前缀后自动附加 Ticket ID。创建时间留空使用服务器当前时间，步长为 0 或省略时默认
  1 毫秒。持续流量使用到达时间，并逐次注入，不使用批量时间或整批撤回选项。
- 流量启动后锁定生成配置与节奏，停止按钮始终可用。“接续编号”将服务端下一 ID 填入
  起始编号，便于再次启动。它不会绕过其他来源创建的重复 ID 检查。

新增 HTTP 字段 `createdAtStep`、`affinityPrefix`、`requestIdPrefix`、`objectFacts` 在
批量与 custom generator 请求中直接映射已有宿主生成器；不修改匹配核心或 Provider
语义。完整请求契约见 [OpenAPI](../../api/openapi/simulator.yaml)。

## 运行一轮

默认“当前时间”在点击时读取时钟，避免旧页面时间影响等待时长。需要可复现实验时选
“指定模拟时间”。本轮最多产出是规则允许时的上限，未满足条件的对象继续等待。

## 交互依据与验证

相关参数分组并保留字段标签，参考 [W3C 表单分组](https://www.w3.org/WAI/tutorials/forms/grouping/)；
低频参数放入可展开的“更多选项”，参考 [NN/g 渐进展示](https://www.nngroup.com/articles/progressive-disclosure/)。

本次真实 API + 浏览器检查覆盖：非法小数明确报错且未创建对象；生成成功后折叠/展开
保留配置；持续流量启动后锁定、停止后恢复并接续编号；窄窗口可访问全部导航。
`composerValidation.test.ts` 覆盖精确区间、循环引用与边界输入；
`TestComposerBatchTimeAndObjectFacts` 通过真实 HTTP 校验时间步长、共同事实和生成前缀。

规则表单参见[使用指南](usage-guide.md)，图表与导出参见 [Match 历史](match-history.md)。
